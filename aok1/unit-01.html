Rule · Qoida
a / an — bitta narsa haqida gapirganda
a + undosh tovusha book, a pen, a map, a chair
an + unli tovush (a, e, i, o, u)an apple, an egg, an orange, an umbrella
Plurals — ko'plik
ko'p so'zlar: +sbook → books, pen → pens
-s, -x, -ch, -sh, -o: +esbus → buses, box → boxes, watch → watches, tomato → tomatoes
undosh + y: y → iesbaby → babies, dictionary → dictionaries
noto'g'ri (yodlang!)child → children, man → men, woman → women, person → people, mouse → mice, foot → feet, tooth → teeth

⚠️ Ko'plikda a / an ishlatilmaydi: a books → books, two books.
