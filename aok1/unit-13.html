Rule · Qoida
Taqqoslash
sifat → -roq → eng
qisqa sifatcheap → cheaper → the cheapest
oxiri -enice → nicer → the nicest
undosh + yeasy → easier → the easiest
qisqa: undosh ikkilanadibig → bigger → the biggest
uzun sifatexpensive → more expensive → the most expensive
noto'g'rigood → better → the best · bad → worse → the worst

than = …dan: This jacket is cheaper than that one. · the + eng: It's the cheapest in the shop.
